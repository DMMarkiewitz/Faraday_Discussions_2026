Collected here are the critical files to reproduce the results displayed in "Thermodynamic effects of solid electrolyte interphase formation from solvation and ionic association in water-in-salt electrolytes" by Daniel M Markiewitz, Michael McEldrew, Conor ME Phelan, Qianlu Zheng, Jasper Singh, Robert S Weatherup, Rosa M Espinosa-Marzal, Martin Z Bazant, Zachary AH Goodwin (https://arxiv.org/abs/2602.23875).

---

The files are set up to be run directly by the user, so long as they are in the correct Active folder subfolder, to be discussed later. 

The files in the Lammps folder are those needed to run the MD simulations to generate the data used. The protocol behind these MD simulations have been previously outlined in "Theory of the double layer in water-in-salt electrolytes" by Michael McEldrew, Zachary AH Goodwin, Alexei A Kornyshev, Martin Z Bazant (https://arxiv.org/abs/1808.06118).

In the Active folder there are two folder, Data Generator and Runners. The Data Generator Codes are used to generate meshes for the theory. These are required for the Runner scripts. To support access, we provide the intial set of meshes/data sets needed for the code to run and reproduce the key figures, these files have a S_ at the start so the default save names do not override them.

Note without these meshes and data sets the runners do have an hierarchy.

For the theory:
	1. FD_2026_EDL_WISE_STI_Theory (Generates Meshes)
	1. Theory_Cluster_Distribution_Plot_Bulk (Generates Bulk Cluster Distribution)
	1. Activity_Bulk (Calculates the bulk activity as a function of molality)
	1. Association_Probablities_Bulk (Calculates the bulk association probability as a function of molality)

		2. Implicit_Poisson_Solver_Sticky_WiSE_EDL_BVP_Panel (Generates Panels)
		2. Implicit_Poisson_Solver_Sti_WiSE_EDL_BVP_Act_Calc (Generates Plots of the activity near and electrode and meshes)
		2. Theory_Cluster_Distribution_Plot_Positive_Surface (Generates Cluster Distribution Plots for the positive electrode)
		2. Theory_Cluster_Distribution_Plot_Negative_Surface (Generates Cluster Distribution Plots for the negative electrode)

			3. Activity_Merge_Plotter (Merges the EDL activity plots into a composite figure)

For the MD simulations analysis, the codes can be run independently. The main data set needed comes from the readDumpFile function, which analysis the MD simulations xyz file to condense the data into the essential elements for our analysis. We include the necessary ones for the 0.2 C/m^2 analysis but the others can be generated by uncommenting the readDumpFile function in either runner.

For the MD simulations analysis:
	1. WiSE_EDL_MD_Processing_Panels (Generates the panels and the associations constants)
	1. WiSE_EDL_MD_Cluster_Dist (Generates the cluster distribution plots)
